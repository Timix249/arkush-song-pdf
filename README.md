# Аркуш — пісня до друку

Невеликий браузерний редактор, який перетворює сирий текст пісні на охайний аркуш для друку.

## Можливості

- вставка тексту будь-якою мовою;
- автоматичне розпізнавання куплетів, приспівів і повторів;
- попередній перегляд;
- друк лише готового аркуша через системне вікно друку;
- збереження результату через «Save as PDF» у вікні друку.

Проєкт не має сервера: текст залишається у браузері користувача.
